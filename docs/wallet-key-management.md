# ECHO Wallet Key Management

## Current Approach

Phase 2 wallets use Ed25519 key pairs generated by Node.js's standard `crypto`
module. Public keys are exported as SPKI PEM. Private keys are exported as
PKCS#8 PEM only through explicit sensitive wallet export.

Wallet creation derives an address from the public key and selected network. A
wallet does not contain a balance, transaction history, UTXOs, or coins. A new
wallet has no blockchain balance because blockchain state does not exist yet.

## Seed Phrases

## Future Deterministic Wallet Requirements

A future deterministic wallet design must specify:

- mnemonic standard
- seed-to-key derivation
- account and address derivation paths
- backup and recovery behavior
- compatibility rules for Ed25519
- migration rules for Phase 2 single-key wallets

## Recovery Requirements

Phase 2 recovery is limited to importing a supported PKCS#8 Ed25519 private key
PEM. Losing the private key means the wallet identity cannot be recovered.

## Security Considerations

Private keys must not be logged, committed, or exposed through public wallet
exports. Encrypted wallet storage is not implemented in Phase 2.
